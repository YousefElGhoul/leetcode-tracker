# LeetCode Tracker frontend

Live at [yousefelghoul.dev/leetcode-tracker](https://yousefelghoul.dev/leetcode-tracker/).

This is part of my larger system of a browser homepage which started as a way to have all my bookmarks in one place and quickly evolved to have multiple apps that offer many quality of life improvements.

## Features
- Shows progress in all LeetCode difficulty categories of questions
- GitHub activity style calendar widget
- Uses the API in [`be/leetcode-tracker`](../be/leetcode-tracker)

## Deployment
Plain HTML, CSS, and JavaScript with no build step. The `Deploy frontend to GitHub Pages` workflow publishes this folder whenever it changes on `main`.

## Notes
This is a personal project; the color theme [(Catppuccin Macchiato)](https://catppuccin.com/) is hardcoded to my preferences. Feel free to fork and change whatever you want.
